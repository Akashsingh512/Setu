# Setu

**Setu** (Sanskrit: "bridge") connects new people with the programs that help them. Teachers and volunteers manage leads, courses and upcoming programs, with a WhatsApp assistant (Digital Volunteer). Built on Supabase (Postgres + Auth), Next.js and Node.
